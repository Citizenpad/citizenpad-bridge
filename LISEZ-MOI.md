# CitizenPad Bridge — téléchargements

Ce dépôt ne contient que les **fichiers à télécharger** de CitizenPad Bridge :

- l'installateur Windows (onglet **Releases**) ;
- les modèles de NOA (branche `noa-modeles`).

Télécharge le Bridge depuis **citizenpad.com** (Réglages → Bridge), ou depuis le Microsoft Store.

# CitizenPad Bridge — downloads

This repository only holds the **downloadable files** of CitizenPad Bridge (installer in **Releases**, NOA models on the
`noa-modeles` branch). Get the Bridge from **citizenpad.com** (Settings → Bridge) or the Microsoft Store.
